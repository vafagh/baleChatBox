ویجیتی چاتی فلۆتکار بۆ جوملا — پەیوەندیی سەردانەکان لەگەڵ بەڕێوەبەری مەشرەت حتی کاتێک کەشوکی ئێنتەرنەت هەیە.
پێکِلەوەری بەلە هەم لە زگەڵ ئێرانەوە و هەم لە دصحەھەوە دەستكەوتە.

## تایبەتمەندیەکان

- **فۆۚمی پەیوەندیی چەند خزمەت** — سەردان بەلە / تیلیگرام / واتساپ بەکار خوش دەكەد
- **ئاگاداریی بۆت** — بەڕێوەبەر لەرێگەڵ بۆتی بەلە (تیلیگرام بە شێوەی خودکار پشتگیریی دەکات)
- **واتساپ**: تەنها خوازیشی پەیوەند — بێ API بۆتی واتساپ؛ بەڕێوەبەر خۆی دەستخۆیی دەكات
- **کاپچا** — Cloudflare Turnstile یان Google reCAPTCHA v2 (به خۆازیشی)
- **بەڕگری CSRF** — تۆکەن لە هەموو نێردانەوە پشکندرەکات
- **بەڕخۆشی سەرکەوتی** — فۆۚم لە نێردانەھێن بە کارتی سەرکەوتی جێگێدرێت
- **پانێلی دهمۆىیی بەڕێوەبەر** — نێردانی بۆت و فۆۚم لە سازاندانی پلاگین
- **چەندزمان** — ئینگلیزی، فارسی، کوردیی سۆڕانی (RTL بە شێوەی كامێل)

## دامەزراندن

1. ZIP لە [ڕێدانی گیتهاب](https://github.com/vafagh/baleChatBox/releases) دابەزێنە
2. پانێلی بەڕێوەبەری جوملا ← **گوزارەکان** ← **بەڕێوەبردن** ← **دامەزراندن** ← **بارکردن**
3. فایلی ZIP بارکەرە
4. **گوزارەکان** ← **پلاگینەکان** ← «Bale ChatBox Widget» بگەڕێ و چالاکبکە

## 🔒 ئەفشای ئامنیەتی و نهێنیی خوسووسی

چونکە ئەم پلاگین دادەکانی سەردان لە ڕێگەڵی پێکێلەوەری بەلە (پلێتفۆرمێکی ئێرانی بەستەكؠرێوایی بە بەنکی نیشتیمانیی ئێران) نێردان دەكات، بەڕێوەبەران دەبێن ئەمانە بزانن.

### ۱. نێردانی دادە و مەلوماتی
- **بێ نێوەندنی سەرتاسەر (E2EE):** ژێژەکانی ئامنیەتی سایبەری (لە باری Open Technology Fund) دەستبەسەردەکەن بەلە نێوەندنی E2EE بەکار نەهێنە. پەیامەکانی سەردان و زانیاریی پەیوەندی بەڕێوەبەر بۆ سێرڤەرەکانی بەڵۆوە بەلە بەرێنا بینین
- **مەلوماتی لێنک:** لێنکەکان بەرێگەڵی سێرڤەرەکانی بەلەدا دەگەڵن

### ۲. مەترسیی حۆکومەتی
- **پلێتفۆرمی دەولەتی:** بەلە بە پێناوی بەندی ئێرانی دا کار دەکات کە رێگەڵی چاودەری بۆ ئەممانە دەدات
- **مەترسیی کەلمەکانی خۆش:** پەیامەکان کە كەلمەو ناوەکانی خۆش یان ناوەکانی سیاسی بن دەن، ممکینە فیلتەر بكرێن یان ئاگادار بکەن

### ۳. باری GDPR و نهێنیی خوسووسی
- **زانیاریی کەسانی (PII):** سەردان زانیارییی كەسانی (شناسه تلگرام، شماره واتساپ، شماره تلفن) نێردان دەکەن
- **نێردانی دادەکانی نێوەندنی:** نێردانی دادە بەږیویی سەردان لە بەڕۆۚهەلدانی ئێرانی ممکینە بێ GDPR دا هەزاواز بکەوە
- **ئاگاداریی ناوخست:** ئەم پلاگین پێش لە نێردانی فۆۚم بۆ سەردانیکانیکە بەلە هەلبژێری دەكەن، پەنجەرەکی ئاگاداریی نهێنیی خوسووسی نیشان دەدات

### ۴. پەیوەندیی لەگەڵ سیستەمی ڕۆخۚانی
بەلە هەموو بە شێوەی یەک ئەپیکێشەنی بەنکی كە بە زێرساختی ڕۆخۚانییکانیی ئێرانی بەستەكؠرێواییە کار دەکات. تمام ھەسابەکانی بەلە بە کارتی نیشتیمانیی ئێرانی بەستەكؠرێواییە

### 💡 بەهترین شێوەکان بۆ بەڕێوەبەران
- **ھەسابی بۆتی جێگاکردراو بەکاربێنە** — هەرگیز زانیاریی ھەسابی كەسانی بەلەت بەکاربێنە
- **زانیاریی كەسانی هەسسیاس ںەوندەکە** (ڕێنجی دێبذینە، زانیاریی ڕۆخۚانی) — ڕێگەڵ بە چوانی نیوەندنی نەكرێڤناوە بەرێگە
- **لۆگەکانی جوملا بکەڤینەوە** — دطمینان حاسیل بکە نێردانەکانی AJAX بەشێوەی دەوام خەملەنەکرێن
