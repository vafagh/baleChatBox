# ویجیتی بێرتی بەله - پلاگینی جوملا

![وەشان](https://img.shields.io/badge/وەشان-1.0.0-blue)
![جوملا](https://img.shields.io/badge/joomla-4%2B-orange)
![PHP](https://img.shields.io/badge/php-8.0%2B-purple)
![مۆڵەت](https://img.shields.io/badge/مۆڵەت-GPL%202.0-green)

پلاگینی سیستەمی جوملای جیاواز و بۆ بەکارهێنانی توندی کاتێ دەکات کە ویجیتێکی چاتی فلۆتکار تێکبدرێت و پشتگیری دەکات لە **بە رێسام بەله** با **تیلیگرام** بە شێوەی خودکار. تێدایە فۆڕمی پەیوەندی بە هێزی AJAX و بەرگری CSRF.

## تایبەتمەندیەکان

✅ **پشتگیری خزمەتی دووجا**
- یەکەم: بە رێسام بەله (tapi.bale.ai)
- پشتگیری: API‌ی بۆتی تیلیگرام (تایم‌اوت شێوەبەندیکراو)

✅ **بینینی ژیرانە بۆ دەستکەوتن**
- بڕگەڕاندن بە شێوەی خودکار بۆ تیلیگرام ئەگەر بەله بەردەست نەبێت
- تایم‌اوت شێوەبەندیکراو (1-10 چرکە)

✅ **فۆڕمی پەیوەندی AJAX**
- بێ تێکۆشانی دووسەری لاپەڕە
- بەرگری توکنی CSRF
- پشکنین و پاکخانی ئینپۆت لە لایەن سێڕڤەر

✅ **پشتگیری زمانی مۆچۆ**
- ئینگلیزی (en-GB)
- فارسی (fa-IR)
- کوردی سۆرانی (ckb-IR)

## دامەزراندن

### گۆڕانی 1: دابەزاندن
ZIP‌ی بۆ دابەزاندن لە [ڕێدانی گیتهاب](https://github.com/vafagh/baleChatBox/releases)

### گۆڕانی 2: بارکردن
1. بڕۆ پانێلی بەڕێوبەری جوملا
2. لە لایەن چەپ: **بەڕێوەبەری** → **کۆمەڵای پلاگین‌ەکان** یان **بەڕێوەبەری** → **دامەزراندنی پلاگین‌ەکان**
3. بڕچاڤی تابی **بارکردن** کراوە (یان **بارکردن**)
4. فایلی `plg_system_bale_chat_1.0.0.zip` دیاریبکەرەوە

### گۆڕانی 3: چالاککردن
1. **پلاگین‌ەکان** → **پلاگین‌ەکان** بڕۆ
2. \"ویجیتی بێرتی بەله\" بگەڕێ
3. وەزیفەی دروست کەرەوە بۆ **چالاک** (دوگمەی سپی)

### گۆڕانی 4: شێوەبەندی
لە پەڕەی پلاگین، ئەم بابەتانە پڕ بکەرەوە:
- **ناوی بۆتی بەله**: ناوی بۆتی پشتگیری بەله‌ی ئێوە
- **ناوی بۆتی تیلیگرام**: ناوی بۆتی تیلیگرامی ئێوە
- سازاندنە دیکەکان (رەنگ، پەیام، جێگرتن)

## شێوەبەندی

| سازاندن | تێگەیشتن |
|---------|-----------|
| **ناوی بۆتی بەله** | ناوی بۆتی پشتگیری بەله‌ی ئێوە |
| **ناوی بۆتی تیلیگرام** | ناوی بۆتی تیلیگرامی ئێوە |
| **رەنگی دوگمە** | رەنگی دوگمەی ویجیت (کۆدی هێکس) |
| **پەیامی بیانوبیاڕێت** | پەیام کاتێک ویجیت کراوە |
| **جێگرتنی ویجیت** | خوار-چەپ یان خوار-راست |
| **تایم‌اوتی پشتگیری** | میلی‌چرکە پێش بڕگەڕاندن بۆ تیلیگرام (1000-10000) |
