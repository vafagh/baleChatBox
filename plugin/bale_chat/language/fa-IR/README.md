# ویجت دوام بله - افزونه جوملا

![نسخه](https://img.shields.io/badge/نسخه-1.0.0-blue)
![جوملا](https://img.shields.io/badge/joomla-4%2B-orange)
![PHP](https://img.shields.io/badge/php-8.0%2B-purple)
![مجوز](https://img.shields.io/badge/مجوز-GPL%202.0-green)

یک افزونه سیستمی جوملا مدرن و آماده برای تولید که یک ویجت چت شناور را تزریق می‌کند و از **پیام‌رسان بله** با **تلگرام** خودکار پشتیبان‌گیری می‌کند. شامل فرم تماس با قدرت AJAX و محافظت CSRF است.

## ویژگی‌ها

✅ **پشتیبانی سرویس دوگانه**
- اصلی: بله پیام‌رسان (tapi.bale.ai)
- پشتیبانی: API بات تلگرام (تایم‌اوت قابل‌تنظیم)

✅ **شناسایی هوشمندانه دسترسی**
- بازگشت خودکار به تلگرام اگر بله دسترس‌پذیر نباشد
- تایم‌اوت قابل‌تنظیم (1-10 ثانیه)

✅ **فرم تماس AJAX**
- بدون بارگذاری مجدد صفحه
- محافظت توکن CSRF
- تایید و تمیزکردن ورودی سمت سرور

✅ **پشتیبانی چند‌زبانه**
- انگلیسی (en-GB)
- فارسی (fa-IR)
- کوردی سورانی (ckb-IR)

## نصب

### مرحله 1: دانلود
ZIP را از [انتشارات گیتهاب](https://github.com/vafagh/baleChatBox/releases) دانلود کنید

### مرحله 2: آپلود
1. به پنل مدیریت جوملا بروید: [https://yoursite.com/administrator/](https://yoursite.com/administrator/)
2. از سمت چپ: **مدیریت** → **مجموعه‌های افزونه** یا **مدیریت** → **نصب افزونه‌ها**
3. روی تب **بارگذاری** کلیک کنید (یا **آپلود**)
4. فایل `plg_system_bale_chat_1.0.0.zip` را انتخاب کنید

### مرحله 3: فعال‌سازی
1. **افزونه‌ها** → **پلاگین‌ها** بروید
2. "ویجت دوام بله" را جستجو کنید
3. وضعیت آن را به **فعال** تغییر دهید (دکمه سبز)

### مرحله 4: پیکربندی
در صفحه پلاگین، موارد زیر را پر کنید:
- **نام بات بله**: نام بات پشتیبانی شما در بله
- **نام بات تلگرام**: نام بات تلگرام شما
- سایر تنظیمات (رنگ، پیام، موقعیت)

## پیکربندی

| تنظیم | توضیح |
|------|-------|
| **نام بات بله** | نام بات پشتیبانی بله شما |
| **نام بات تلگرام** | نام بات تلگرام شما |
| **رنگ دکمه** | رنگ دکمه ویجت (کد هگز) |
| **پیام خوش‌آمدگویی** | پیام هنگام باز شدن ویجت |
| **موقعیت ویجت** | پایین-چپ یا پایین-راست |
| **تایم‌اوت پشتیبانی** | میلی‌ثانیه قبل از بازگشت به تلگرام (1000-10000) |
