ویجت چت شناور برای جوملا — ارتباط بازدیدکنندگان با مدیر سایت را حتی در زمان اختلالات اینترنت حفظ می‌کند.
پیام‌رسان بله هم از داخل و هم از خارج از ایران قابل دسترس است.

## ویژگی‌ها

- **فرم تماس چندسرویسه** — بازدیدکننده بله / تلگرام / واتساپ را به عنوان کانال ترجیحی انتخاب می‌کند
- **اعلان بات** — مدیر از طریق بات بله (تلگرام به عنوان پشتیبان) اطلاع‌رسانی می‌شود
- **واتساپ**: فقط ترجیح تماس بازدیدکننده — بدون API بات واتساپ؛ مدیر به صورت دستی پیگیری می‌کند
- **کپچا** — Cloudflare Turnstile یا Google reCAPTCHA v2 (اختیاری)
- **محافظت CSRF** — توکن در هر ارسال اعتبارسنجی می‌شود
- **تجربه کاربری موفق** — فرم پس از ارسال با یک کارت موفقیت جایگزین می‌شود
- **پنل آزمایش مدیر** — آزمایش بات و فرم از تنظیمات افزونه
- **چندزبانه** — انگلیسی، فارسی، کوردی سورانی (با پشتیبانی کامل RTL)

## نصب

1. ZIP را از [انتشارات گیتهاب](https://github.com/vafagh/baleChatBox/releases) دانلود کنید
2. پنل ادمین جوملا ← **افزونه‌ها** ← **مدیریت** ← **نصب** ← **بارگذاری**
3. فایل ZIP را آپلود کنید
4. **افزونه‌ها** ← **پلاگین‌ها** ← «Bale ChatBox Widget» را پیدا و فعال کنید

## 🔒 افشای امنیتی و حریم خصوصی

چون این افزونه داده‌های بازدیدکننده را از طریق پیام‌رسان بله (یک پلتفرم ایرانی مرتبط با بانک ملی ایران) ارسال می‌کند، مدیران سایت باید از موارد زیر آگاه باشند.

### ۱. انتقال داده و مانیتورینگ
- **بدون رمزنگاری سرتاسری (E2EE):** ممیزی‌های امنیت سایبری (از جمله توسط Open Technology Fund) تأیید می‌کنند که بله از رمزنگاری E2EE استفاده نمی‌کند. پیام‌های بازدیدکننده و اطلاعات تماس ارسال‌شده از طریق بات شما برای سرورهای بک‌اند بله قابل مشاهده است.
- **مانیتورینگ لینک‌ها:** لینک‌های ارسال‌شده از طریق بات از سرورهای بله عبور می‌کنند و آدرس‌های وب دسترسی‌یافته ثبت می‌شوند.

### ۲. خطر نظارت دولتی
- **پلتفرم دولتی:** بله تحت مقررات داخلی ایران که اجازه مانیتورینگ ارتباطات را «برای اهداف امنیتی» می‌دهد، فعالیت می‌کند.
- **خطر سانسور:** پیام‌هایی که حاوی کلمات کلیدی خاص، محتوای سیاسی یا اشاره به پلتفرم‌های مسدودشده هستند ممکن است فیلتر یا علامت‌گذاری شوند.

### ۳. تعهدات GDPR و حریم خصوصی
- **اطلاعات شخصی (PII):** بازدیدکنندگان از طریق این فرم اطلاعات قابل شناسایی شخصی (شناسه تلگرام، شماره واتساپ، شماره تلفن) ارسال می‌کنند.
- **انتقال داده بین‌المللی:** ارسال داده‌های کاربر از یک سایت که خارج از ایران میزبانی می‌شود به زیرساخت پیام‌رسانی ایرانی ممکن است با GDPR یا سایر قوانین بین‌المللی حریم خصوصی بدون رضایت صریح بازدیدکننده در تضاد باشد.
- **اعلان داخلی:** این افزونه قبل از ارسال فرم برای بازدیدکنندگانی که بله را به عنوان کانال تماس انتخاب می‌کنند، یک پنجره اطلاعیه حریم خصوصی نشان می‌دهد.

### ۴. همپوشانی با سیستم مالی
بله همزمان به عنوان یک اپلیکیشن بانکی مرتبط با زیرساخت مالی ایران فعالیت می‌کند. تمام حساب‌های بله به کارت ملی ایرانی مرتبط هستند.

### 💡 بهترین روش‌ها برای مدیران
- **از یک حساب بات اختصاصی استفاده کنید** — هرگز اطلاعات شخصی بله خود را وارد نکنید.
- **اطلاعات حساس جمع‌آوری نکنید** (رمز عبور، اطلاعات مالی) — کانال را به عنوان متن رمزنگاری‌نشده در نظر بگیرید.
- **لاگ‌های جوملا را بررسی کنید** — اطمینان حاصل کنید که ارسال‌های AJAX در صورتی که فقط به عنوان مسیریاب استفاده می‌شوند، به طور دائم ذخیره نمی‌شوند.
