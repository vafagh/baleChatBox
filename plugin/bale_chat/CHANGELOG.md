# Changelog

All notable changes to Bale ChatBox Widget will be documented in this file.

## [1.0.0] - 2024-04-01

### Added
- Initial public release
- Bale Messenger integration
- Telegram Bot API fallback
- AJAX-powered contact form
- CSRF token protection
- Multi-language support (English, Persian, Kurdish-Sorani)
- RTL (Right-to-Left) support
- Customizable widget position and color
- Server-side input validation and sanitization
- Modern Joomla 4+ architecture

### Technical
- PHP 8.0+ compatible
- Joomla 4.x and 5.x support
- Service Provider pattern
- Event-based plugin system
